# 📺 Приложение для учёта телевизоров

Простое веб-приложение для подсчёта телевизоров на фотографиях с использованием нейросети YOLOv8.

## 📁 Структура проекта

```
tv-counter/
├── app.py              # Основной код приложения (Flask + YOLO)
├── requirements.txt    # Список зависимостей
├── templates/
│   ├── index.html      # Главная страница (загрузка фото)
│   └── history.html    # Страница истории
├── static/             # Папка для обработанных изображений
└── history.db          # База данных (создаётся автоматически)
```

## 🚀 Быстрый старт

### 1. Установка зависимостей

Откройте терминал и выполните:

```bash
cd tv-counter
pip install -r requirements.txt
```

Это установит:
- `ultralytics` — библиотека для работы с YOLOv8
- `opencv-python` — для обработки изображений
- `flask` — веб-фреймворк
- `openpyxl` — для экспорта в Excel

### 2. Запуск приложения

```bash
python app.py
```

При первом запуске:
- Скачается модель YOLOv8 (около 6 МБ)
- Создастся база данных `history.db`
- Создастся папка `static/`

### 3. Открытие в браузере

Перейдите по адресу: **http://localhost:5000**

## 📖 Как пользоваться

### Главная страница

1. Нажмите "Выберите файл" и загрузите фотографию с телевизорами
2. Нажмите кнопку "Распознать телевизоры"
3. Подождите 10-30 секунд (первый раз дольше)
4. Посмотрите результат:
   - Количество найденных устройств
   - Изображение с зелёными рамками

### Страница истории

1. Нажмите "История" в меню
2. Просматривайте все предыдущие распознавания
3. Скачайте отчёт в Excel (кнопка "Скачать Excel")

## 🎯 Что распознаёт модель

YOLOv8 ищет на изображении:
- **Телевизоры** (class 72 в COCO)
- **Мониторы** (class 72)
- **Ноутбуки** (class 73)
- **Телефоны** (class 67)

> Все эти устройства имеют экраны, поэтому распознаются вместе.

## 📊 База данных

При каждом распознавании сохраняется:
- Имя загруженного файла
- Имя обработанного файла
- Количество найденных устройств
- Время обработки

Все данные хранятся в файле `history.db` (SQLite).

## ⚠️ Возможные проблемы

### "Module not found"
```bash
pip install -r requirements.txt
```

### "CUDA out of memory"
Приложение автоматически использует GPU, если он доступен. Если ошибка — будет работать на CPU (медленнее).

### Медленная работа
Первый запуск медленный — модель скачивается и инициализируется. Последующие запуски быстрее.

## 📝 Для отчёта

### Описание работы приложения

1. **Пользователь** загружает фотографию через веб-интерфейс
2. **Flask-сервер** получает файл и передаёт его в нейросеть
3. **YOLOv8** анализирует изображение и находит объекты
4. **Результат** сохраняется в БД, пользователь видит:
   - Количество найденных устройств
   - Изображение с нарисованными рамками
